- **Scope:** Images → containers → volumes → networks → Dockerfile → Compose → registries.

## Docker Fundamentals

Docker is an open platform for developing, shipping, and running applications inside **containers** — lightweight, isolated processes that share the host OS kernel. Compared to virtual machines, containers start in seconds, use fewer resources, and produce identical environments across development, staging, and production.
