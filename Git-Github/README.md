## Useful Tips & Tricks

- Use `git help <command>` or `git <command> --help` to view the manual for any Git command.
- Use `git status` often to see the current state of your working tree.
- Use `git log --oneline --graph --all` for a compact visual history.
- Use `.gitignore` to exclude files/folders from version control.
